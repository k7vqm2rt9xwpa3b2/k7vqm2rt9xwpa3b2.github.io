Projects

Check out an assortment of what I've been working on. As you can see, it both intersects with my interests and shows my development approach. Everything here is on GitHub and licensed so others can use it.

Music Library Curation

For those of us who still maintain a local music library, upkeep is paramount (and part of the fun!).

Lyricsmith

An advanced suite for adding synced and untimed lyrics to all your songs. No need to be jealous of anyone with a streaming service.

  • Album

    Finds both synced and untimed lyrics for every track on an album using a variety of sources. It can write LRC/TXT sidecar files or embed SYLT/USLT lyrics directly into MP3s.

  • Sweep

    Runs Album across a whole library, one album at a time.

  • Sync

    For songs that only have untimed lyrics available, this matches them to the song's own audio. It works offline to separate the vocals and align the words to them.

  • Transcribe

    For songs with no lyrics available (or genres like stand-up comedy that generally don't have them), this generates timed and untimed lyrics offline directly from the audio file.

Apple Music Toolbox

For the Mac users out there, a set of tools to get more out of the Apple Music desktop app.

  • Album Stats

    Reports various stats about an album, such as track count, favorite tracks, and year.

  • Recently Added

    Finds the albums most recently added to Apple Music.

  • Tag Refresh

    Makes the Music app reread the tags of MP3s that changed on disk, so the lyrics, titles, and album names it shows match the files again.

Environment Remedies

Frictions exist in every development environment. Here are a few solutions for the ones that got annoying enough to fix.

Claude Tools

Claude certainly has its quirks, especially regarding sessions and token usage. Here are a few tools to improve the experience. Note that these might go out of date one day if Anthropic fixes those quirks.

  • Usage Window Primer

    Keeps a Claude subscription's five-hour usage window running while the machine is unattended, so a fresh window is already open when you return.

  • Remote Session Reviver

    A Claude desktop app scheduled task that keeps the app's Code-tab sessions reachable from a phone through Remote Control, even after app updates and restarts turn it off.

Workspace Safeguards

A busy workspace often introduces issues that aren't immediately apparent.

  • Git Workspace Backup

    Developing on a single computer can be dangerous, even when using remote version control. This tool keeps a daily backup of an entire environment on an external drive.

  • APFS TM Snapfree

    Git worktrees and Time Machine don't play nicely with your APFS drive when you have a lot of sessions going on. This is one way of keeping their snapshots permanently in check.

Process Guardrails

Checks that run before anything ships, so pages, docs, and schedules stay right for every branch.

Page Proofs

These tools pull a proof of a website by checking speed, rendering, and printing behavior on your own machine before anything goes live.

  • Lighthouse Run

    Measures each page with a pinned version of Lighthouse, running several passes and keeping the median so one slow run can't skew the score.

  • Browser Pass

    Renders every page in Chromium, Firefox, and WebKit, at every screen size, in light and dark, with scripts on and off, and flags where one engine's layout differs from the others.

  • Print Pass

    Prints every page to PDF in Chrome and Firefox and compares the results, so a printed page comes out as expected.

DocTether

Docs drift the moment the code changes. These checks tie each doc to what it describes and fail the build when the two disagree.

  • ShellCheck MD

    Runs ShellCheck over every shell example in your Markdown, so a broken command in a README fails the build instead of reaching your readers.

  • CLI Doc Consistency

    Compares a Python tool's documentation with the options its parser actually defines, and fails when one is missing, renamed, or out of date.

OS Schedule Generator

Every OS schedules jobs its own way. Describe a weekly or daily job once and get the right file for Windows, Linux, and macOS.

  • Command Line

    Turns one schedule into ready-to-install scheduler files for every platform, written to a folder you choose.

  • Library

    Hands back the same scheduler files as text, for Python code that builds its own scheduled jobs.

Website Flourishes

A collection of tools made specifically to enhance this site.

Decorative Crossword

A fun generator so you can go from a word bank to a puzzle. The emphasis here is on relaxing the game's rules just enough to focus on design and presentation.

  • Fill

    Searches for a grid that fits your word bank, size, and density, and keeps the best one it finds. Pin the answers you want featured and it builds around them.

  • Preview

    Draws any grid as an SVG, including ones made by hand, so you can see its shape before using it.

  • Shade

    Finds a hidden word the finished grid can spell in shaded squares, choosing cells that scatter across the grid like a printed crossword's.

  • Gaps

    Shows which blocked cells could still hold a letter, and what words the bank would need to fill them.

Media Feeds

Various tools for querying both local and network APIs to generate reports on recent media consumption history.

  • Album Scan · Cover Art

    Finds the most recently added albums and fetches each one's cover art at a chosen size.

  • Film Scan · Wikidata Director

    Reads a public Letterboxd diary feed for the most recently watched films, then looks up each film's director through Wikidata.

  • Book Scan · Feed Read

    Scans a public Goodreads shelf feed for the most recently read books.
